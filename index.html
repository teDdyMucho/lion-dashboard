How to read this dashboard
Days to clear
If no new work came in, how many working days until every open work order is finished. This is the main number to watch.
Status
up to 5 days (one work week)   5–10 days   more than 10 days
LVL (effort points)
Every work order gets a level from 1 (quick job) to 5 (big job). Adding them up gives the total effort waiting.
Daily capacity
How many LVL points the zone's technicians can finish in one day (the number next to each tech's name).
Not yet assigned
Work orders still marked New — nobody is working on them yet.
Where the data comes from
The Portfolio Maintenance & Backlog Google Sheet (link in the sidebar). The page reloads it every 10 minutes.
